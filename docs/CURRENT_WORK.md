## Текущий этап

**Название:** Исправление визуальной системы, адаптивности и доступности по результатам UI-аудита  
**Статус:** 🔵 В работе  
**Дата:** 2026-11-02

### Выполнено

- Подключено окно настройки Ollama / LM Studio: выбор провайдера, проверка списка моделей, сохранение endpoint/model/temperature/system prompt.
- Статус соединения зависит от доступности провайдера и наличия выбранной модели.
- Реализованы hash-маршруты экранов, исправлено отображение рабочей папки терминала.
- Опрос браузерного screenshot ограничен открытым экраном и видимой вкладкой.
- Для пяти тем затемнены цвета CTA; белый текст на используемом однотонном фоне акцентной кнопки имеет контраст не ниже WCAG AA.
- Добавлены тематические переопределения основных поверхностей, форм, навигации и акцентных кнопок.
- На узких экранах вместо скрытой боковой панели отображается горизонтальная навигация на главной и в настройках.
- Добавлены семантические href для внутренних экранов и подразделов настроек.
- Добавлены focus-visible, reduced-motion и управление фокусом модальных окон.
- Сброс пользовательского шрифта очищает style element, file input и подпись.

### Проверки

| Проверка | Результат | Примечание |
|---|---|---|
| JS syntax: app.js / settings.js | Пройдено | V8 `new Function` |
| CSS brace balance | Пройдено | Баланс фигурных скобок |
| Дубликаты ID index.html | Не обнаружены | Статическая проверка |
| Контраст CTA | Расчётно соответствует AA | Для однотонного значения кнопки; фактический рендер ещё требует браузерной проверки |
| DOM-селекторы JS | Не найдено отсутствующих ID | Проверены статические селекторы app.js и settings.js относительно соответствующих HTML |
| API-маршруты | Не найдено отсутствующих маршрутов | Все API-пути, найденные во frontend JS, сопоставлены с маршрутами backend |
| Внутренние CSS/JS/HTML ресурсы | Найдены в репозитории | Проверены ссылки на app.css, settings.js, app.js и settings.html |
| Backend startup / API | Не проверено | Локальный процесс недоступен |
| Браузерный QA | Не проверено | Требуется браузер пользователя |

### Следующие действия

1. Проверить фактическое отображение пяти тем и всех экранов в браузере.
2. Пройти ссылки, формы, модальные окна, keyboard navigation и мобильные ширины.
3. Проверить сохранение/сброс пользовательского шрифта и тем после перезапуска.
4. Выполнить регрессионную проверку подключения моделей, чата, журналов, терминала, браузера и плагинов.

### Ограничения

Статические проверки не подтверждают визуальный результат, работу фокуса в браузере или подключение к реальному runtime. Эти проверки остаются открытыми.
