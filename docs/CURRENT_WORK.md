**Название:** Исправление выявленных проблем интерфейса по результатам статического аудита  
**Статус:** 🔵 В работе

### Контекст

Проведён расширенный статический аудит главной страницы, страницы настроек, CSS, JavaScript и backend-маршрутов. Это не заменяет запуск приложения и браузерный QA. Актуальная исходная точка перед исправлениями: commit `caa877859c74d89351e04dbac2e2d74751d7655a`.

### Выполнено в первом пакете исправлений

- [x] Подключены кнопка «Настроить подключение» и модальное окно провайдера.
- [x] Реализованы выбор Ollama / LM Studio, проверка соединения через фактический запрос списка моделей, обновление списка и сохранение адреса, модели, температуры и системной инструкции через существующий API.
- [x] Статус главной страницы теперь проверяет доступность AI-провайдера и наличие выбранной модели, а не только загрузку конфигурации.
- [x] Реализована обработка маршрута `/#operations` и других поддерживаемых экранов при загрузке и изменении hash.
- [x] Устранено обращение к отсутствующему `terminalCwd`; добавлен элемент отображения рабочей папки.
- [x] Опрос скриншотов браузера выполняется только при открытом экране браузера и видимой вкладке.

### Оставшиеся задачи аудита

1. Полная токенизация CSS и корректировка контрастности пяти светлых тем.
2. Мобильная навигация главной страницы и настроек.
3. Семантика ссылок, keyboard navigation, focus-visible и reduced motion.
4. Доступность модальных окон: dialog semantics и управление фокусом.
5. Сброс загруженного шрифта без остаточного состояния.
6. Браузерный QA на целевых разрешениях, проверка ссылок, форм, сохранения настроек и консоли.

### Ограничения

- Изменения первого пакета подтверждены статическим анализом; функционально в браузере они ещё не проверены.
- Реальное подключение к локальной модели не подтверждено без запуска приложения на компьютере пользователя.
