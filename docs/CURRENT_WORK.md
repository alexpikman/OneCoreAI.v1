### Выполнено

- Главное меню перестроено в пять разделов по README §14.1: Рабочее пространство, Процессы, AI-ресурсы, Доступ, Настройки.
- Чат и история оставлены в рабочем пространстве; журнал операций помещён в Процессы; провайдеры и модели — в AI-ресурсы; браузер, терминал, инструменты, GitHub/SSH, плагины и безопасность — в Доступ; поведение, контекст и внешний вид — в Настройки.
- Для задач, агентов, очередей, автоматизации и назначения моделей агентам показан статус «Планируется»; несуществующая функциональность не представлена как рабочая.
- Добавлена адаптивная компактная навигация для мобильной ширины.

- Все разделы настроек встроены в `frontend/index.html` как внутренний экран единого SPA; отдельная страница `settings.html` удалена.
- Навигация настроек работает через hash-подразделы `#settings/...`; переходы из чата, кнопки модели и рабочей папки открывают нужный раздел без перехода на другую HTML-страницу.
- Сохранённые настройки синхронизируются с состоянием чата через событие `onecore:settings-saved`.
- Скрипт настроек изолирован в IIFE для исключения конфликтов глобальных объявлений.

- Подключено окно настройки Ollama / LM Studio: выбор провайдера, проверка списка моделей, сохранение endpoint/model/temperature/system prompt.
- Статус соединения зависит от доступности провайдера и наличия выбранной модели.
- Реализованы hash-маршруты экранов, исправлено отображение рабочей папки терминала.
- Опрос браузерного screenshot ограничен открытым экраном и видимой вкладкой.
- Для пяти тем затемнены цвета CTA; белый текст на используемом однотонном фоне акцентной кнопки имеет контраст не ниже WCAG AA.
- Добавлены тематические переопределения основных поверхностей, форм, навигации и акцентных кнопок.
- На узких экранах вместо скрытой боковой панели отображается горизонтальная навигация на главной и в настройках.
- Добавлены семантические href для внутренних экранов и подразделов настроек.
- Добавлены focus-visible, reduced-motion и управление фокусом модальных окон.
- Сброс пользовательского шрифта очищает style element, file input и подпись.

### Незакрытая часть визуальной системы

Полная миграция всех цветовых значений на семантические CSS-токены ещё не завершена. В текущем CSS остаётся около 305 вхождений hex-цветов (207 уникальных значений); часть относится к декоративным деталям и компонентам, которые требуют отдельного сопоставления с токенами. Не следует считать тему полностью унифицированной только по наличию пяти наборов `data-theme`.
